Privacy Policy

Last updated: 4 October 2026

1. Overview

NextSignal Publisher ("the app") is a private desktop tool used only by NextSignal Tech to publish its own videos to its own YouTube, TikTok and Instagram accounts. This policy explains what data the app handles.

2. Data the app accesses

  • YouTube (YouTube API Services): permission to upload videos and read basic channel information (channel name), for NextSignal Tech's own channel only.
  • TikTok: basic profile information (user ID and display name), and permission to upload and publish videos to NextSignal Tech's own TikTok account.
  • Instagram: the account ID and username of NextSignal Tech's own Instagram professional account, and permission to publish Reels to it.

The app does not access other users' data, followers' data, messages, comments or analytics.

3. How data is used

Data is used only to upload and schedule NextSignal Tech's videos and to show which account is connected. It is not used for advertising, profiling or any other purpose.

4. Storage and security

Access tokens and settings are stored only on NextSignal Tech's own computer, in a file readable only by its owner. Nothing is stored on external servers operated by NextSignal Tech.

5. Sharing

Data is not sold, rented or shared with anyone. It is sent only to the platform it belongs to (Google/YouTube, TikTok or Meta/Instagram) when publishing.

6. Google and YouTube

The app uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. Access can be revoked at any time at Google security settings.

7. Revoking access and deleting data

Access can be removed at any time by disconnecting the account in the app, which deletes the stored token, or by revoking access in each platform's settings: Google account permissions, TikTok's Settings → Security → Manage app permissions, or Instagram's Settings → Apps and websites. To ask for any data to be deleted, email nextsignalstudionews@gmail.com and it will be removed within 30 days.

8. Children

The app is not directed at children and is used only by NextSignal Tech.

9. Changes

This policy may be updated from time to time. The date at the top shows when it last changed.
